## Uso del repositorio

1. Abrir una Issue por tarea o hallazgo e indicar objetivo y responsable cuando el equipo lo acuerde.
2. Realizar el cambio en una rama y abrir un pull request que enlace la Issue.
3. Adjuntar resultados o evidencia; solicitar revisión a otro integrante.
4. Integrar el cambio revisado y cerrar la tarea cuando exista evidencia de cumplimiento.

Los resultados del ciclo original se conservan. Para nuevas ejecuciones usar archivos nuevos con fecha. Un fallo del proveedor se mantiene abierto hasta verificar su corrección; no se cierra por terminar la entrega académica.
